خطوات رفع المشروع مجاناً على GitHub Pages

هذا النظام مبني بالكامل داخل ملف index.html قياسي (Single-File SPA) بدون أي اعتماد على سيرفر خلفي، مما يجعله جاهزاً للنشر الفوري عبر GitHub Pages:

1. تهيئة المستودع محلياً ورفع الكود

git init git branch -M main git add index.html git commit -m "feat: deploy 3rd secondary math track study system" git remote add origin https://github.com/YOUR_USERNAME/thanaweya-math-tracker.git git push -u origin main

2. تفعيل الاستضافة من إعدادات GitHub

  • افتح مستودعك على GitHub ثم انتقل إلى تبويب Settings ثم قسم Pages من القائمة الجانبية.
  • تحت قسم Build and deployment (Source) اختر Deploy from a branch.
  • حدد الفرع main والمجلد / (root) ثم اضغط Save.
  • خلال دقيقة سيعمل النظام مباشرة على الرابط: https://<username>.github.io/thanaweya-math-tracker/
